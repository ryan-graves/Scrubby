# FileScrubby

A native macOS app for batch renaming files with a visual preview and customizable renaming rules.

## Features

**Renaming Operations**
- **Find & Replace** - Replace text patterns in filenames (supports regex)
- **Prefix/Suffix** - Add text to the beginning or end of filenames
- **Replace Filename** - Replace the entire filename while preserving the extension
- **File Format** - Convert filenames to different formats (hyphenated, camelCase, snake_case)
- **Sequential Numbering** - Add incrementing numbers as prefix or suffix with configurable starting number and padding

**Workflow**
- Choose multiple files to rename
- Stack multiple renaming steps that execute in order
- Reorder steps with move up/down controls
- Live preview of the renamed filenames before committing changes
- Move originals to a selected destination or create renamed copies
- Option to overwrite existing files or add numbered suffixes to duplicates

**Presets**
- Save your renaming step configurations as presets
- Quickly apply saved presets to new batches of files
- Manage and organize your preset library

## Requirements

macOS 26.0 or later
